# Phase n1 spec: 5G NR sync finder (`iqnr.py`, `tools/iq-nr`)

Goal: from a recording, find every 5G NR cell's synchronisation block (SSB): its frequency on the NR sync raster
(GSCN), its subcarrier spacing, its physical cell ID (PCI, 0-1007), its SSB index and half-frame (from the PBCH DM-RS),
its period, and a chance estimate. NR's sync signals are not LTE's (m-sequences, not Zadoff-Chu), so `iq-lte` calls
an NR carrier only "possible". Numpy only in the repo, like `iqlte.py`. This phase decodes nothing: no PBCH bits,
no MIB, no polar decoding. Later phases (n2, n3) hand the block to an outside decoder for the MIB, SIB1 and SIB9.

Read `CLAUDE.md`, `AGENTS.md`, `knowledge/lte-verify.md`, `tools/fm_receiver/iqlte.py` (its docstring's method and
wrong turns, `sss_search` and its chance estimate), `tools/iq-lte` (file handling, options, exit codes, JSON),
`tools/tests/lte_synth.py`, `tools/tests/lte_negatives.py`, `tools/tests/test_iqlte.py` (style of ok/FAIL checks),
`tools/tests/run_all.py`.

Base: `main`. Every worktree is made from `main`. The planner has already committed this spec on `main`; nothing
else goes to `main`. Nothing is merged or pushed: the branches go to the planner (merge list in the report).

## The standard (copy exactly; TS 38.211, 38.213, 38.104)
- **SSB:** 4 OFDM symbols x 240 subcarriers (k = 0..239). The sync raster frequency SS_REF is subcarrier k = 120.
  PSS: symbol 0, subcarriers k = 56..182. SSS: symbol 2, k = 56..182. PBCH: symbols 1 and 3 (k = 0..239) and
  symbol 2 (k = 0..47 and 192..239). Nothing else in the SSB's symbol 0 and symbol 2 gaps (k 0..55, 183..239 of
  symbol 0, k 48..55 and 183..191 of symbol 2 are zero).
- **PSS** (38.211 7.4.2.2): d(n) = 1 - 2 x((n + 43 N_ID2) mod 127), n = 0..126, x(i+7) = (x(i+4) + x(i)) mod 2,
  initial [x(6)..x(0)] = [1 1 1 0 1 1 0] (that is x(0)=0, x(1)=1, x(2)=1, x(3)=0, x(4)=1, x(5)=1, x(6)=1).
- **SSS** (7.4.2.3): d(n) = [1 - 2 x0((n + m0) mod 127)] [1 - 2 x1((n + m1) mod 127)], m0 = 15 floor(N_ID1/112) +
  5 N_ID2, m1 = N_ID1 mod 112; x0(i+7) = (x0(i+4) + x0(i)) mod 2, x1(i+7) = (x1(i+1) + x1(i)) mod 2, both with
  x(0)=1, x(1..6)=0. PCI = 3 N_ID1 + N_ID2, N_ID1 0..335, N_ID2 0..2.
- **PBCH DM-RS** (7.4.1.4.1 and table 7.4.3.1-1): r(m) = [(1 - 2c(2m)) + j(1 - 2c(2m+1))]/sqrt(2), m = 0..143,
  c = the length-31 Gold sequence (Nc = 1600, as in LTE, see `lte_synth._gold`) with c_init = 2^11 (i_bar + 1)
  (floor(PCI/4) + 1) + 2^6 (i_bar + 1) + (PCI mod 4). For L_max = 4: i_bar = i_SSB + 4 n_hf (i_SSB 0..3, n_hf the
  half-frame bit 0/1); for L_max = 8: i_bar = i_SSB mod 8 (no half-frame bit). The 144 DM-RS go, in increasing k
  then increasing symbol, to subcarriers k = v, v+4, ..., v+236 of symbol 1; k = v..v+44 step 4 and v+192..v+236
  step 4 of symbol 2; k = v..v+236 step 4 of symbol 3; v = PCI mod 4. PBCH data uses the other PBCH subcarriers.
- **OFDM, normal CP** (38.211 5.3.1), at fs = nfft x scs: each symbol nfft samples plus a CP of 144 nfft/2048
  samples; the first symbol of every 0.5 ms (symbol 0 and symbol 7 x 2^mu of a subframe; mu = 0 at 15 kHz, 1 at
  30 kHz) has 16 x 2^mu x nfft/2048 samples more. Example nfft = 256: CP 18, long CP 20 (15 kHz) or 22 (30 kHz).
- **SSB positions in a 5 ms half frame** (38.213 4.1): the first symbol of each candidate SSB (symbol index counted
  from the half frame's start, at that SCS):
  case A (15 kHz): {2, 8} + 14 n; n = 0, 1 at or below 3 GHz (L_max 4), n = 0..3 above 3 GHz (L_max 8).
  case B (30 kHz): {4, 8, 16, 20} + 28 n; n = 0 at or below 3 GHz (L_max 4), n = 0, 1 above (L_max 8).
  case C (30 kHz): {2, 8} + 14 n; n = 0, 1 at or below 3 GHz (L_max 4), n = 0..3 above (L_max 8).
  Candidate i_SSB counts in that order. A cell sends some of them (often only one) every period (5, 10, 20, 40,
  80 or 160 ms; 20 is usual).
- **Sync raster** (38.104 table 5.4.3.1-1):
  0-3000 MHz: SS_REF = N x 1200 kHz + M x 50 kHz, N = 1..2499, M in {1, 3, 5}, GSCN = 3N + (M - 3)/2 (2..7498).
  3000-24250 MHz: SS_REF = 3000 MHz + N x 1.44 MHz, N = 0..14756, GSCN = 7499 + N (7499..22255).
  Worked examples (made up, not real cells): GSCN 2 = 1.25 MHz, 3 = 1.35 MHz, 4 = 1.45 MHz, 1499 = 600.05 MHz,
  1500 = 600.15 MHz, 1501 = 600.25 MHz, 7499 = 3000.00 MHz, 8000 = 3721.44 MHz, 22255 = 24248.64 MHz.
  Raster points are 100 kHz apart inside a group of three and 1000 kHz between groups (below 3 GHz).

## Test signal (`tools/tests/nr_synth.py`; numpy builds the waveform, scipy only resamples)
- `synth_nr(pci=123, scs_khz=15, case='A', l_max=4, ssb_sent=(0,), period_ms=20, n_hf=0, bw_mhz=10,
  ssb_offset_hz=0.0, dur_ms=100, snr_db=20.0, cfo_hz=0.0, fs=None, seed=0, load=1.0)` returns `(iq, fs, truth)`.
  The carrier is `bw_mhz` wide (used subcarriers floor(bw_mhz x 1e6 x 0.9 / scs)) centred at 0 Hz; the SSB sits at
  `ssb_offset_hz` from the centre and must fit inside it. SSBs are sent at the candidate positions `ssb_sent`
  (of `case`, `l_max`), in half frame `n_hf` of each `period_ms` (for period 5 ms, in every half frame, n_hf
  alternating 0/1). PBCH data REs and every non-SSB RE of the carrier carry random QPSK with probability `load`
  (seeded). The SSB's REs have the same mean power as data REs. The radio frame starts at a seeded random offset
  0-10 ms into the capture, so sample 0 is not a boundary. Native rate nfft x scs with nfft the smallest power of
  two at least 1.2 x bw_mhz x 1e6 / scs; `fs` other than native resamples (`resample_poly`). Noise and `snr_db`
  use the same convention as `lte_synth.synth_lte` (signal power over noise power at the output rate; non-finite
  adds none). `cfo_hz` rotates the result. `truth` holds pci, nid1, nid2, scs_khz, case, l_max, ssb_sent, n_hf,
  period_ms, ssb_offset_hz, fs, frame_start_s and the start time (s) of every SSB sent.
- `synth_nr_multi(cells, bw_mhz=..., dur_ms=100, snr_db=20.0, fs=40e6, seed=0)`: `cells` a list of dicts with the
  `synth_nr` keywords plus `power_db` and `carrier_offset_hz` (the carrier centre from the capture centre); each
  cell has its own data and frame timing; noise added once.
- `__main__` writes nothing and prints a self-check (PSS correlates with the truth's N_ID2 at the truth's times).

## Interface (`tools/fm_receiver/iqnr.py`)
- `gscn_to_hz(gscn) -> float` (ValueError outside 2..22255); `hz_to_gscn(hz, tol_hz=1000.0) -> int | None` (None
  when no raster point is within `tol_hz`).
- `raster_in_band(center_hz, fs, scs_khz) -> list[(gscn, hz)]`, ascending: every GSCN whose whole SSB
  (SS_REF +/- 120 x scs) lies inside center_hz +/- 0.45 fs.
- `ssb_search(iq, fs, center_hz, ssb_hz=None, scs_khz=None, max_cells=4) -> list` of dicts, strongest first:
  `ssb_hz, gscn (hz_to_gscn(ssb_hz)), scs_khz, pci, nid1, nid2, ssb_index, half_frame (None when L_max is 8),
  l_max, period_ms (None with fewer than two bursts seen), bursts (count), first_ssb_s, cfo_hz, pss_score,
  sss_score, sss_next, chance, dmrs_score, dmrs_chance, relative_power_db (0.0 for the strongest), detail`.
  With `ssb_hz` given: only that frequency (SCS from `scs_khz`, or both 15 and 30 tried). With `ssb_hz` None: every
  raster point of `raster_in_band` for 15 kHz and for 30 kHz (or only `scs_khz`). Only cells whose SSS chance is at
  most 1e-3 are listed (a PCI is never guessed), and at most one entry per (gscn, pci). L_max is 4 at or below
  3 GHz, 8 above (from `ssb_hz`). Under 2 ms, under 3.84 MS/s, or noise: `[]`, no exception.
- CFO: works with a carrier offset up to +/- 5 kHz at 15 kHz and +/- 10 kHz at 30 kHz (an oscillator a few ppm off).

## Command (`tools/iq-nr`)
`tools/iq-nr FILE [--rate HZ --center HZ] [--t0 S] [--seconds S] [--ssb-hz HZ] [--scs 15|30] [--max-cells N]`.
Rate and centre from the `.sigmf-meta` beside the file, as `iq-lte` does; options override. Reads only the span
[t0, t0 + seconds] (default 0.1 s; at most 2 s, a longer request is cut and says so), never the whole file: peak
memory stays proportional to the span. Stdout one JSON document: `file, rate, center_hz, t0, seconds, verdict
("nr" when at least one SSB is listed, else "none"), reason, ssbs` (the `ssb_search` list). Exit 0 when the run
completed, whatever the verdict; exit 1 for a bad option, an unreadable file, a sweep file, or no centre frequency.

## Gates (pre-registered)
- G0 (the manager runs it, after synth and before tests): the planner's independent reference
  `python3 <OPS>/ref/nr_ref.py FILE.cfile FS CENTER_HZ SSB_HZ SECONDS SCS_KHZ` (numpy; reads complex64) on
  `synth_nr` files saved as complex64 (PCI 123 and 1007, 15 kHz case A, 10 MHz, 20 dB; PCI 217, 30 kHz case C,
  20 MHz; 100 ms; `ssb_offset_hz` 0 and +1.5 MHz): prints `best PSS: nid2 X` equal to PCI mod 3 and `SSS ... best
  nid1 Y (PCI Z)` equal to the truth in 6 of 6. A failure goes back to the synth author; nothing else starts until
  6 of 6.

- G2 B: right PCI in at least 19 of 20.
- G3 C: right GSCN, SCS and PCI in at least 18 of 20; no entry at a wrong GSCN in at least 19 of 20.
- G4 D: both PCIs at their own GSCNs in at least 4 of 5.
- G5 E: ssb_index and half_frame right in at least 22 of 24; period_ms right in 10 of 10.
- G6 F: `[]` in 30 of 30; both short captures 2 of 2, no exception.
- G7 G: 9 of 9 examples both ways; the None and both ValueErrors.
- G8 H: 4 of 4.
- G9 I: raster mode under 30 s; with `ssb_hz` under 5 s; `iq-nr` peak RSS under 700 MB; `test_iqnr.py` plus
  `test_iq_nr.py` under 240 s together (load below 0.75 x cores; the manager measures with `time`).
- G10 J all pass. `iqnr.py` and `iq-nr` import only numpy, the standard library and `fm_receiver`; no file outside
  the ownership table changes; every existing suite and `run_all.py` pass.
- G11 (the planner, not delegated, real air; real values kept outside the repo): on the planner's recorded 850 MHz
  captures, `iq-nr` in raster mode lists each SSB the planner found by hand, at the same GSCN and PCI; on the
  planner's recorded LTE carrier and ATSC capture: no SSB. Run under `systemd-run --user --scope -p MemoryMax=3G`.
- Bake-off rubric (0-100): gates G1-G9 weighted by case count 50; robustness 20 (the consensus run scores it from
  the entry's own output on: SNR -3 dB case A; a 5 ms period; three SSBs sent (0, 1, 3); 40 MS/s raster search of a
  carrier at 3721.44 MHz with L_max 8 and centre 3720 MHz); spec compliance 15 (interface, numpy only, chance
  never a guess); clarity 15 (docstring with method and wrong turns).
- Winner rule: only an entry passing G1, G3, G6 and G7 is eligible; highest score wins; ties go to fewer confirmed
  [high] review items. If none is eligible, the best gets one fix round; if it still fails, report.
- Controls: G6 is the negative control (LTE must not read as NR); G3's "no entry at a wrong GSCN" guards against a
  search that reports neighbours of the true raster point.

## Rules for every prompt and file
- Made-up identifiers only: the PCIs and frequencies above. No real PCI, GSCN, ARFCN, PLMN, cell identity or
  captured data in any file, test, prompt or commit. Muse trains on prompts.
- Nothing here reads anything but the sync signals; no decoding of any channel.
- Workers do not read `/data/python/lte-tools`, `/data/python/SDR`, `/data/sceptre`, `recordings/`, the ops folder
  or any path outside their worktree. Only the manager runs `<OPS>/ref/nr_ref.py`.
